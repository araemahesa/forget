# Bahasa dan Konten

Ikuti bahasa, karakter, tone dan istilah yang diminta. Dialog harus mendukung tujuan interaksi, pilihan dan konsekuensi; pertanyaan umum dijawab tanpa mengarang lore. Jangan memaksakan bahasa Indonesia pada teks artefak jika pengguna meminta bahasa lain. Pertahankan token/placeholder dan nama API saat menerjemahkan.

Periksa ejaan, konsistensi istilah, kepanjangan teks, line break, truncation, angka dan simbol pada ukuran tampil sebenarnya. Desain ruang untuk teks lebih panjang tanpa mengklaim sistem localization otomatis. Untuk branching, cek target node, pilihan buntu, state quest dan restart. Jangan menambahkan informasi pribadi atau fakta dunia nyata yang belum diperiksa. Teks dekoratif tidak menggantikan instruksi interaksi yang jelas.

Input: prompt, kontrak fitur, referensi dan konteks yang tersedia. Output: panduan untuk provider pilihan; tidak memberi akses tool baru. Terapan hanya sesuai scope dan kemampuan nyata.
