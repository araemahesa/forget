# ForgeKit Studio 0.1.47 — 6 November 2026

Rilis ini menggabungkan semua pekerjaan 6 November: streaming chat, konektor MCP, penulisan Studio dengan guard dan persetujuan, serta perbaikan audit. Rincian ada di:

- [MCP_STREAMING_STUDIO_WRITES_2026_11_06.md](MCP_STREAMING_STUDIO_WRITES_2026_11_06.md)
- [AUDIT_FIXES_2026_11_06.md](AUDIT_FIXES_2026_11_06.md)

## Tambahan pada rilis ini

- **Mode kerja chat.** Pemilih di composer: *Kerjakan* (perubahan perlu izin), *Tanya* dan *Rencanakan* (baca saja; backend tidak memberi tool tulis). Pilihan diingat.
- **Sinkronisasi Obsidian** hanya berjalan saat tugas selesai, tidak di setiap checkpoint, sehingga kunci database tidak tertahan selama tugas berjalan.
- **Viewport 3D tersembunyi** hanya mengecek dua kali per detik apakah halamannya dibuka lagi.
- **CI GitHub Actions** (`.github/workflows/ci.yml`): typecheck, tes, dan build frontend di Ubuntu; tes Rust di macOS, untuk setiap PR dan push ke `main`.
- Perbaikan otomatis clippy; komponen `TaskProgressCard` yang tidak dipakai dihapus.

## Pemasangan

Mengikuti prosedur pemasangan sebelumnya: aplikasi lama ditutup normal agar draf tersimpan, database dan aplikasi lama dibackup ke `~/Library/Application Support/ForgeKit Recovery/`, aplikasi baru diverifikasi tanda tangannya, dan tabel chat/karya dibandingkan sebelum dan sesudah. Saat dibuka pertama kali, database naik dari skema 15 ke 16 (snapshot `forgekit-before-schema-16-*` dibuat otomatis). Bukti: `docs/test-evidence/2026-11-06/release-0.1.47/installation.json`.
